# Render mustache templates to JS

This folder contains a tiny example on how to use this lib with Kotlin's JavaScript
compiler in the browser.

It's straightforward. I wanted to try it. Maybe it will help you too.

1. Run `./gradlew :js-sample:browserProductionLibraryDistribution`.
2. go to `js-sample/build/dist/js/productionLibrary` and open `index.html`
